# Microsoft x64 ABI

All freestanding translation units target `x86_64-pc-windows-msvc`.
Kernel calls use RCX/RDX/R8/R9, four shadow slots, 16-byte caller stack alignment
and stack arguments after the shadow area. The assembly probe writes every shadow
slot and independently weights six arguments. C-to-assembly and host-to-assembly
tests verify placement, alignment and scalar return. An assembly caller seeds
RBX/RBP/RDI/RSI/R12–R15 and checks their preservation across a compiled C callee
in both the host and kernel. Hosted aggregate tests check
by-value input and hidden return storage on Windows.

The kernel excludes SIMD instructions until extended CPU state ownership exists.
Compiler-generated `.pdata`/`.xdata` is emitted and the structural inspector checks
runtime-function extents. This is not runtime unwinder validation. Privileged
stack-transfer and terminal trap stubs are explicit boundaries without a claimed
general unwind contract. Nonvolatile XMM preservation probes, unwind
opcode interpretation, SEH, varargs, syscall ABI and differential NT structure
layout tests remain required before binary compatibility is declared.
